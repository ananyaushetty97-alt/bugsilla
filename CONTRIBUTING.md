# Contributing to Bugsilla

1. Create a branch from `main` using the `codex/` prefix for Codex-created branches.
2. Install dependencies with `npm install`.
3. Run `npm run dev` for local work.
4. Run `npm run build` before opening a pull request.
5. Keep runtime files, credentials, databases, and uploads out of commits.

Please describe visible behavior changes and include reproduction steps for bug fixes.
